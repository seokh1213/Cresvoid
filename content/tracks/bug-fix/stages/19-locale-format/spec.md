# 가격 문자열 출력

[1] 쇼핑 카탈로그의 상품 가격과 할인율로 구매 알림 문구와 정산 파일의 행을 만든다. 주문을 접수할 때 견적을 보관하고, 나중에 상품 가격이 바뀌어도 접수한 견적으로 문서를 다시 발행할 수 있다. 외부 정산 시스템은 고정된 숫자 형식만 읽는다. 이 프로그램은 파일을 직접 저장하지 않고 생성한 문구와 행을 표준 출력에 쓴다.

[2] 표준 입력에서 한 줄에 명령 하나를 읽어 EOF까지 처리한다. 명령과 인자는 하나 이상의 공백으로 구분하며 앞뒤 공백과 빈 줄은 무시한다. 명령 이름은 대문자로 쓴다. 각 명령은 결과를 한 줄 출력한다. 실행할 때마다 상품 목록과 보관한 견적은 비어 있고 서버의 기본 Locale은 `en-US`다. 문서 양식은 알림 접두어 `NOTICE`, 정산 행 접두어 `ROW`인 `default` 하나가 등록돼 있으며 처음 선택한 양식도 `default`다.

## 서버 설정과 상품

[3] `LOCALE <태그>`는 서버의 기본 Locale을 바꾸고 `OK`를 출력한다. 지원하는 태그는 `en-US`, `ko-KR`, `de-DE`, `fr-FR`, `ar-EG`다. 설정은 다음 명령부터 유지되며 상품 정보와 보관한 견적은 바뀌지 않는다. `STATUS`는 현재 설정과 상품 수를 `STATUS <태그> <상품 수>`로 출력한다. 기본 Locale 변경은 다른 서버 기능에도 쓰이므로 출력 형식을 고치면서 이 설정의 효과를 없애면 안 된다.

[4] `PUT <상품 ID> <단가> <할인율>`은 상품을 등록하고 `OK`를 출력한다. 이미 있는 ID면 단가와 할인율을 모두 교체한다. ID는 영문 대소문자·숫자·하이픈·밑줄로 이루어진 1~30자 문자열이며 대소문자를 구분한다. 단가는 0~1,000,000,000 사이의 정수 원이다. 할인율은 0~10,000 사이의 정수이며 1은 0.01%, 150은 1.50%, 10,000은 100.00%를 뜻한다.

[5] `SHOW <상품 ID>`는 저장된 값을 가공하지 않고 `PRODUCT <상품 ID> <단가> <할인율>`로 출력한다. `STATUS`의 상품 수와 `SHOW`의 수치는 천 단위 구분자와 불필요한 앞자리 0 없이 ASCII 숫자로 출력한다.

## 문서 양식

[5.1] `REGISTER <양식 ID> <알림 접두어> <정산 행 접두어>`는 두 접두어를 가진 양식을 등록하고 `OK`를 출력한다. 양식 ID와 두 접두어의 표기는 [4]의 상품 ID와 같다. 이미 있는 양식 ID면 양식 전체를 교체한다. 등록은 현재 선택한 양식 ID를 바꾸지 않는다. 선택한 ID의 양식을 교체하면 이후 즉시 발행과 새 견적은 교체한 양식을 쓴다. 상품·양식·견적의 ID는 서로 별도로 관리한다.

[5.2] `SELECT <양식 ID>`는 이후 즉시 발행과 새 견적에 사용할 양식을 선택하고 `OK`를 출력한다. 보관한 견적에는 영향을 주지 않는다. 문법이 올바르지만 등록하지 않은 양식 ID면 `ERROR unknown-layout`을 출력하고 기존 선택을 유지한다. `default`도 다시 등록하거나 선택할 수 있다.

## 가격 계산과 문서

[6] `NOTICE <상품 ID> <수량>`과 `EXPORT <상품 ID> <수량>`은 현재 상품 정보로 가격을 계산한다. 수량은 1~10,000 사이의 정수다. 원가는 단가에 수량을 곱한 값이다. 할인액은 원가에 할인율 정수를 곱하고 10,000으로 나눈 값에서 원 미만을 버린 정수다. 결제액은 원가에서 할인액을 뺀 값이다. 할인액은 개당 계산한 뒤 더하지 않고 주문 전체 원가에서 한 번 계산한다. 조회와 출력은 저장된 상품을 변경하지 않는다.

[7] 알림과 정산 행의 모든 금액은 ASCII 숫자로 쓰고 오른쪽부터 세 자리마다 쉼표를 넣는다. 할인율의 소수점은 마침표로 쓰고 소수 둘째 자리까지 항상 표시한다. 이 숫자 형식은 서버 설정에 관계없이 같다. 금액 0은 `0`, 할인율 정수 150은 `1.50`, 0은 `0.00`, 10,000은 `100.00`이 된다. 수량은 구분자 없는 ASCII 정수다.

[8] `NOTICE`는 `NOTICE <상품 ID> quantity=<수량> total=<결제액>원 discount=<할인율>%`로 출력한다. `EXPORT`는 `ROW|<상품 ID>|<수량>|<원가>|<할인액>|<결제액>|<할인율>`로 출력한다. 위 출력의 `NOTICE`와 `ROW`는 `default` 양식의 초기 접두어다. 양식을 등록하면 알림 맨 앞의 `NOTICE`와 정산 행 맨 앞의 `ROW`만 등록한 접두어로 바꾼다. 입력 명령 이름은 바뀌지 않는다. 정산 행에는 헤더·따옴표·추가 공백을 넣지 않는다. 여기서 금액과 할인율은 [7]의 형식을 따른다.

## 견적 보관과 재발행

[8.1] `FREEZE <견적 ID> <상품 ID> <수량>`은 현재 상품 정보로 [6]의 가격을 계산해 보관하고 `OK`를 출력한다. 견적 ID의 표기는 [4]의 상품 ID와 같지만 두 ID는 별도로 관리한다. 이미 있는 견적 ID면 견적 전체를 교체한다. 상품의 단가·할인율을 바꾸거나 서버 설정을 바꾸어도 보관한 견적의 원가·할인액·결제액·할인율·수량은 바뀌지 않는다.

[8.2] `DRAFT <견적 ID>`는 보관한 견적을 `QUOTE <견적 ID> <상품 ID> <수량> <원가> <할인액> <결제액> <할인율 정수>`로 출력한다. 모든 수치는 천 단위 구분자와 불필요한 앞자리 0 없이 ASCII 숫자로 출력한다. 할인율은 [4]의 정수 단위를 그대로 쓴다.

[8.3] `NOTICE <견적 ID>`와 `EXPORT <견적 ID>`는 보관한 견적의 문서를 [7]과 [8]의 형식으로 출력한다. 상품 ID 뒤에 수량이 붙는 명령과 달리 현재 상품으로 다시 계산하지 않는다. 같은 견적을 여러 번 발행한 결과는 같아야 하며 조회와 발행은 보관한 견적을 변경하지 않는다. 견적을 보관할 때와 문서를 발행할 때의 서버 설정이 달라도 숫자 형식은 같다.

[8.4] `FREEZE`는 당시 선택한 양식의 접두어도 견적에 함께 보관한다. 나중에 같은 양식 ID를 다시 등록하거나 다른 양식을 선택해도 보관한 견적의 문서는 바뀌지 않는다. 같은 견적 ID로 성공한 `FREEZE`를 다시 실행하면 가격과 양식을 모두 새로 보관한다. `DRAFT`에는 양식 접두어를 출력하지 않는다.

## 잘못된 명령

[9] 명령 이름·인자 수·ID·정수 표기·수치 범위·Locale 태그 중 하나라도 올바르지 않으면 `ERROR invalid-command`를 출력하고 상태를 바꾸지 않는다. 정수 표기는 ASCII 숫자만 허용하며 앞자리 0은 허용한다. 문법과 범위가 올바른 `SHOW`와 상품을 지정한 `NOTICE`, `EXPORT`, `FREEZE`에서 상품이 없으면 `ERROR unknown-product`를 출력한다. 견적을 지정한 `DRAFT`, `NOTICE`, `EXPORT`에서 견적이 없으면 `ERROR unknown-quote`를 출력한다. 실패한 `FREEZE`는 같은 ID로 이미 보관한 견적을 지우지 않는다. 오류가 나도 다음 줄을 계속 처리한다.

## 버그 신고

[10] 아래는 가상의 정산 장애 신고다. 서버를 증설한 뒤 보관 견적의 정산 파일 일부가 거절됐다. 같은 상품을 즉시 발행하면 접수되는데 보관 견적을 재발행하면 거절된다. 양식 문구를 교체하고 상품 가격을 다시 등록해도 예전 견적의 문제는 남는다. 두 견적의 원시 수치는 같고 문구는 접수 당시의 양식을 따른다. 상품·견적·양식 중 무엇이 영향을 주는지 확인해야 한다.

[11] 전달받은 재현 입력은 다음과 같다.

```text
LOCALE fr-FR
REGISTER retail ALERT SALE
SELECT retail
PUT kettle 1299000 150
EXPORT kettle 3
LOCALE de-DE
FREEZE morning kettle 3
REGISTER retail UPDATE INVOICE
EXPORT kettle 3
FREEZE noon kettle 3
PUT kettle 5900 0
LOCALE en-US
DRAFT morning
DRAFT noon
EXPORT morning
EXPORT noon
NOTICE morning
FREEZE evening kettle 3
EXPORT evening
SELECT default
EXPORT kettle 3
STATUS
```
