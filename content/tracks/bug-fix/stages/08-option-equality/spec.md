# 장바구니 상품 옵션 비교

## 1. 제품 맥락

[1.1] 쇼핑 카탈로그 서비스의 장바구니를 처리한다. 상품마다 색상, 크기, 포장처럼 구매자가 고른 옵션이 있다. 같은 상품을 같은 옵션으로 다시 담으면 기존 항목의 수량을 늘린다. 다른 상품이나 다른 옵션이면 새 항목을 만든다.

[1.2] 프로그램은 빈 장바구니로 시작한다. 표준 입력에서 명령을 한 줄씩 EOF까지 읽고 결과를 표준 출력에 쓴다. 출력의 각 줄은 LF로 끝내며 마지막 입력 줄에 LF가 없어도 처리한다. 빈 줄과 공백만 있는 줄은 출력 없이 건너뛴다.

## 2. 입력과 옵션

[2.1] 명령어와 인자는 ASCII 공백 하나 이상으로 나눈다. 줄 앞뒤에도 공백이 올 수 있다. 상품 ID, 옵션 이름, 선택값은 `[A-Za-z0-9_-]+`에 맞는 문자열이며 대소문자를 구분한다. 명령어는 대문자다. 입력은 이 문서의 명령 형식과 범위를 지킨다.

[2.2] 옵션 인자는 `이름=값,값;이름=값` 형식이다. 옵션이 없으면 `-`로 쓴다. 옵션 이름은 한 인자 안에서 중복되지 않으며, 각 옵션에는 하나 이상의 선택값이 있다. 같은 이름 안에서 선택값은 중복되지 않는다. 옵션 이름과 선택값에는 구분 문자 `=`, `,`, `;`와 공백이 들어가지 않는다.

[2.3] 두 옵션 묶음은 옵션 이름이 모두 같고, 이름별 선택값이 모두 같으면 같다. 옵션 이름을 나열한 순서와 한 이름의 선택값을 나열한 순서는 비교에 영향을 주지 않는다. 이름이나 선택값 하나라도 다르면 다른 옵션 묶음이다. 옵션이 없는 두 묶음은 같다.

[2.4] 옵션을 출력할 때는 이름을 문자열 오름차순으로 정렬하고 각 이름의 선택값도 문자열 오름차순으로 정렬한다. 이름과 값 사이에는 `=`, 선택값 사이에는 `,`, 옵션 사이에는 `;`를 쓰고 공백은 넣지 않는다. 옵션이 없으면 `-`를 출력한다. 정렬은 대소문자를 구분하는 Kotlin 문자열의 자연 순서를 따른다.

## 3. 장바구니 명령

[3.1] `ADD <상품 ID> <수량> <옵션>`은 상품을 담는다. 상품 ID와 옵션 묶음이 모두 같은 항목이 있으면 수량을 더한다. 없으면 새 항목을 만든다. 결과는 `ADDED <항목 ID> <처리 후 수량>` 한 줄이다. 기존 항목에 합쳤다면 항목 ID와 목록에서의 위치를 유지한다.

[3.2] 항목 ID는 처음 만든 항목부터 1, 2, 3 순으로 부여한다. 기존 항목에 수량을 더할 때는 ID를 소비하지 않는다. 항목을 지워도 그 ID를 재사용하지 않는다. 같은 상품과 옵션을 삭제 뒤 다시 담으면 새 ID를 부여한다.

[3.3] `QUANTITY <상품 ID> <옵션>`은 상품 ID와 옵션 묶음이 모두 같은 항목의 수량을 `QUANTITY <수량>`으로 출력한다. 해당 항목이 없으면 `QUANTITY 0`을 출력한다. 이 명령은 장바구니를 바꾸지 않는다.

[3.4] `SET <항목 ID> <수량>`은 해당 항목의 수량을 입력한 수량으로 교체하고 `SET <항목 ID> <처리 후 수량>`을 출력한다. 상품 ID, 옵션, 항목 ID, 목록 순서는 바뀌지 않는다. 항목이 없으면 `NOT_FOUND <항목 ID>`를 출력하고 장바구니를 바꾸지 않는다.

[3.5] `REMOVE <항목 ID>`는 해당 항목을 삭제하고 `REMOVED <항목 ID>`를 출력한다. 항목이 없으면 `NOT_FOUND <항목 ID>`를 출력하고 장바구니를 바꾸지 않는다.

[3.6] `SHOW`는 먼저 `CART <항목 수> <전체 수량>`을 출력한다. 이어서 항목 ID가 작은 순으로 항목마다 `LINE <항목 ID> <상품 ID> <수량> <옵션>`을 한 줄씩 출력한다. 전체 수량은 모든 항목의 수량을 더한 값이다. 빈 장바구니는 `CART 0 0` 한 줄만 출력한다. 옵션은 2.4의 형식으로 출력한다.

[3.7] ADD와 SET의 수량은 1 이상 1,000,000 이하의 10진 정수다. 항목 ID 인자는 1 이상 1,000,000 이하의 10진 정수다. 정수는 선행 0 없이 쓴다. 한 실행의 명령은 최대 100,000개이며, 어떤 시점에도 장바구니 전체 수량은 1,000,000,000을 넘지 않는다.

## 4. 버그 신고

[4.1] 장바구니 화면을 확인하다가 보낸 신고다. “토트백과 머그를 담고 수량도 고친 뒤 목록을 열었는데 토트백이 예상보다 여러 줄로 보인다. 수량 합계는 맞아 보이지만 담은 상품을 확인하기 어렵다. 화면에서 수행한 작업을 아래 명령으로 옮겼다.”

[4.2] 재현 입력이다.

```text
ADD tote 1 color=navy;strap=long
ADD mug 2 -
SET 2 3
ADD tote 1 color=navy;strap=long
ADD tote 1 color=rust;strap=long
QUANTITY mug -
REMOVE 2
ADD pouch 1 -
ADD pouch 2 -
SHOW
```

[4.3] 기대한 출력이다.

```text
ADDED 1 1
ADDED 2 2
SET 2 3
ADDED 1 2
ADDED 3 1
QUANTITY 3
REMOVED 2
ADDED 4 1
ADDED 4 3
CART 3 6
LINE 1 tote 2 color=navy;strap=long
LINE 3 tote 1 color=rust;strap=long
LINE 4 pouch 3 -
```

[4.4] 실제 출력이다.

```text
ADDED 1 1
ADDED 2 2
SET 2 3
ADDED 3 1
ADDED 4 1
QUANTITY 3
REMOVED 2
ADDED 5 1
ADDED 5 3
CART 4 6
LINE 1 tote 1 color=navy;strap=long
LINE 3 tote 1 color=navy;strap=long
LINE 4 tote 1 color=rust;strap=long
LINE 5 pouch 3 -
```
