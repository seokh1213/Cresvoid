# 읽기

긴 한국어 비문학을 끝까지 정확히 읽는 힘을 기른다. 형식은 수능 국어 비문학과 LEET 언어이해를 따른다. 문항은 내용 일치보다 `<보기>` 적용과 추론을 중심에 둔다.

## 1. 출제 기준

- 지문은 새로 쓴다. 기존 시험 지문, 교과서 문단, 번역문을 옮기지 않는다.
- 사실관계는 1차 자료로 확인한다. 확인하지 못한 세부 사실은 넣지 않는다.
- 개념 사이의 조건, 인과, 대비, 예외 관계를 촘촘하게 담는다. 문단마다 문항이 물을 거리가 하나 이상 있어야 한다.
- 문항은 5~6개다. 구성은 내용 일치 1, 추론 1, 개념 비교 1, `<보기>` 적용 1~2, 여러 문단을 엮는 고난도 종합 1 을 기본으로 한다.
- `<보기>` 는 세 가지 가운데 하나 이상을 쓴다. 수치를 넣어 계산하는 사례, 요건을 단계적으로 따지는 사례, 표나 그래프로 준 자료다.
- 오답 선지는 지문을 부분적으로 비튼다. 상식만으로 지울 수 있는 선지를 만들지 않는다.
- 난도는 단계가 오를수록 높인다. 글자 수 2,100~3,300자, 문단 6~8개, 목표 시간 10~15분 안에서 정한다.
- 블라인드 풀이에서 정답이 하나로 모이고 지문의 사실 서술이 모두 확인될 때까지 고친다(`content/skills/cresvoid-reading-track`).
