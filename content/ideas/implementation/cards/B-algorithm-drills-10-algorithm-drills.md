# B-algorithm-drills-10 주제별 알고리즘 문제 묶음

- 목표: 짧은 알고리즘 문제를 주제별 명령 묶음으로 풀며 경계값과 시간 복잡도를 의식하는 습관을 되살린다. 한 단계는 문제 5~7개를 명령으로 묶는다(D30).
- 입출력 모양: 한 줄에 명령 하나(예: `PALINDROME text`, `ANAGRAM a b`, `MAXWINDOW k n a1 … an`)를 처리하고 결과를 한 줄로 출력한다. 출력은 입력만으로 정해진다. 앞 단계 명령은 뒤 단계에서도 그대로 동작한다.
- 1단계 `01-strings`: 회문 판정(영숫자만 보고 대소문자 무시), 애너그램, 카이사르 암호, 가장 많이 나온 문자(동점 규칙), 같은 문자 반복 여부, 부분 문자열 찾기(표준 라이브러리 검색 함수 없이), 문장의 단어 첫 글자 대문자.
- 2단계 `02-arrays`: 크기 k 창의 최대 합, 합이 목표 이상인 가장 짧은 연속 구간, 정렬된 배열의 서로 다른 값 개수, 평균이 목표인 두 수 찾기, 두 정렬 배열의 중앙값, 금액을 만드는 동전 조합 수.
- 3단계 `03-sort-search`: 첫 위치와 마지막 위치를 찾는 이진 탐색, 병합 정렬, 정렬된 입력에서도 느려지지 않는 퀵 정렬, k번째로 작은 값, 가장 큰 k개.
- 4단계 `04-structures`: 스택과 두 스택으로 만든 큐, 두 큐를 번갈아 합치기, 단일·이중 연결 리스트 명령(삽입, 삭제, 뒤집기, 가운데 원소), 이진 탐색 트리(삽입, 검색, 순회, 유효성 검사), 최소 힙.
- 5단계 `05-grids-recursion`: 나선 행렬 생성, 격자에서 직사각형 찾기, 계단과 피라미드 출력, 가능한 모든 쌍 만들기, 큰 피보나치 수(메모이제이션과 `BigInteger`).
- 난도: 단계마다 1~2시간. 문제 하나는 쉽지만 대규모 입력(n = 10^6)이 단순한 O(n²) 풀이를 제한 시간 밖으로 밀어낸다.
- 함정: 빈 입력, 동점 규칙, 합과 곱의 정수 넘침, 대소문자 변환의 로캘, 정렬된 입력에서의 퀵 정렬, 깊은 재귀.
- 검증: build 스킬의 교차 검증. 작은 입력에서는 완전 탐색 풀이와 비교하고 큰 입력으로 시간 한도를 확인한다.
- 출처: 문제 주제는 kotlin-lab `challenges`의 원본인 igorwojda/kotlin-coding-challenges(MIT)의 목록에서 골랐다. 알고리즘의 사실은 Cormen 외 "Introduction to Algorithms" 4판(MIT Press, 2022)으로 확인한다.
- 피할 것: 원본 저장소의 문제 문장, 예시, 테스트를 옮기는 것(D15). C-kotlin-40의 LRU 캐시. 문제마다 단계를 따로 두는 것.
