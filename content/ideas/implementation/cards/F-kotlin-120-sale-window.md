# F-kotlin-120 타임세일 시작과 끝

- 맥락: 타임세일은 시작 시각부터 종료 시각 직전까지 할인가를 적용한다(시작 포함, 종료 제외). 세일 일정과 주문 시각은 입력 명령으로 준다. 연속한 두 세일이 맞닿을 수 있다(앞 세일의 종료 시각이 뒤 세일의 시작 시각과 같다).
- 버그 후보: 구간 판정을 `start < t && t <= end` 로 써서 시작 시각의 주문은 정가가 되고 종료 시각의 주문은 할인가가 된다(먼저 고른다. 맞닿은 두 세일에서는 경계 시각 주문이 앞 세일 가격을 받는다), 시작 시각 순으로 정렬한 세일 목록에서 `binarySearch` 의 음수 반환값(없으면 -(삽입 위치)-1)을 잘못 풀어 경계 시각에 앞 세일을 고른다.
- 버그 신고: "10시에 시작한 세일에서 10시 정각 주문은 정가로 결제됐다. 10시에 끝난 앞 세일의 할인가를 받은 주문이 있다."
- 형식: 150~220줄, 파일 2~3개.
- 난도: 경계 시각을 정확히 넣은 입력에서만 증상이 난다.
- 검증: 숨은 테스트는 시작 시각, 종료 시각, 맞닿은 세일의 경계 시각을 모두 둔다. 비교 연산자를 고치거나 반열린 구간 함수를 만든 수정이 모두 통과해야 한다.
- 출처: Java SE 21 API 문서의 `Instant.isBefore` 와 `isAfter`.
- 피할 것: C-kotlin-20 의 java.time 경계 문항과 같은 상황을 그대로 쓰는 것. F-kotlin-30 과 같은 시간대 원인.
