# B-search-engine-30 자동 완성

- 목표: 접두로 시작하는 토큰을 문서 빈도 순으로 빠르게 고르고, 문서를 더하거나 지우면 순위를 바로 맞춘다.
- 입출력 모양: `SUGGEST <k> <접두>` 가 후보 토큰과 문서 빈도를 순위대로 한 줄에 출력한다.
- 단계별 내용: 접두 정규화(1단계 토큰화 규칙), 후보는 지금 색인에 있는(문서 빈도 1 이상) 토큰, 정렬은 문서 빈도 내림차순 다음 토큰 순서, k 상한, ADD·DEL 뒤 바로 반영.
- 난도: 대규모 테스트는 어휘 20만 개 이상과 한두 글자 접두가 많은 질의로 만든다. 접두 범위의 토큰을 매번 모두 훑는 방법으로는 제한 시간을 넘게 한다. 트라이 노드마다 상위 후보를 유지하는 방법과 정렬된 어휘 위의 구간 최댓값 구조를 배경 개념으로 설명한다.
- 함정: 접두와 같은 토큰의 포함 여부, 문서 빈도가 같을 때의 순서, DEL 로 문서 빈도가 0 이 된 토큰, 같은 id 로 ADD 해 문서를 대체할 때의 문서 빈도 변화, 한글 음절 접두.
- 검증: 참조 풀이와 독립 테스트의 교차 검증, 무작위 생성기로 단순 구현과 대조.
- 출처: Elastic 문서의 Completion suggester(접두 자동 완성의 동작과 한계).
- 피할 것: 오타를 허용하는 자동 완성(B-search-engine-20 과 겹친다), 여러 낱말로 된 구문 자동 완성.
