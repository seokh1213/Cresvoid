# B-search-engine-20 오타 허용 검색

- 목표: 편집 거리 기반 후보 생성을 큰 어휘에서도 빠르게 한다.
- 다룰 내용: 낱말 단위 레벤슈타인 거리 정의(삽입, 삭제, 교체 비용 1), `FUZZY <k> <낱말>` 같은 새 명령, 거리 상한 2, 후보가 여럿일 때의 정렬 규칙(거리 오름차순, 문서 빈도 내림차순, 토큰 사전순), 기존 QUERY·SEARCH 와의 관계(바꾸지 않는다).
- 난도: 대규모 테스트(어휘 20만 개, 질의 5천 개)가 모든 어휘와 거리를 계산하는 방법으로는 제한 시간을 넘게 만든다. BK-트리나 트라이와 동적 계획법 행 가지치기를 배경 개념으로 설명한다.
- 함정: 같은 거리의 정렬 규칙, 한글 음절과 영문이 섞인 토큰, 거리 0(정확 일치)의 포함 여부.
- 검증: 참조 풀이와 독립 테스트의 교차 검증, 무작위 생성기로 무식한 계산과 대조.
