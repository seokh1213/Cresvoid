# F-kotlin-10 커서 페이지네이션

- 맥락: 상품 목록 API 를 흉내 낸 명령 처리기다. 상품을 판매량 내림차순으로 보여 주고 판매량이 같으면 상품 ID 오름차순이다. 다음 페이지는 앞 페이지의 마지막 항목으로 만든 커서에서 이어 읽는다. 페이지 사이에 상품 추가 명령이 끼어들 수 있다.
- 버그 후보: 커서에 판매량만 담고 동점 처리 키(상품 ID)를 빼서 같은 판매량의 상품이 페이지 경계에서 빠지거나 겹친다(먼저 고른다), 다음 페이지가 있는지를 `가져온 수 == 페이지 크기` 로 판정해 빈 마지막 페이지를 한 번 더 보여 준다.
- 버그 신고: "판매량이 같은 상품이 많은 카테고리에서 페이지를 넘기면 어떤 상품은 두 번 보이고 어떤 상품은 보이지 않는다." 재현 입력, 기대한 목록, 실제 목록을 함께 적는다.
- 형식: 150~220줄, 파일 2~3개.
- 난도: 첫 세 단계 가운데 가장 쉽다. 증상에서 원인까지 한 단계 추론으로 닿는다.
- 검증: 숨은 테스트는 동점이 페이지 경계에 걸치는 입력과 걸치지 않는 입력을 모두 둔다. 커서 형식을 다르게 고친 수정도 통과해야 한다.
- 출처: Markus Winand, "Use The Index, Luke" 의 키셋 페이지 넘기기 설명.
- 피할 것: DB 와 SQL. 메모리 목록으로 흉내 낸다.
