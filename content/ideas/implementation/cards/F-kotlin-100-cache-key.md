# F-kotlin-100 회원 등급별 가격 캐시

- 맥락: 회원 등급마다 할인가가 다른 상품 가격을 캐시해 상품 목록 응답을 빠르게 만든다. 가격은 상품 ID, 회원 등급, 쿠폰 적용 여부로 정해진다. 캐시 항목에는 만료 시각이 있고 시각은 입력 명령으로 움직인다.
- 버그 후보: 캐시 키에서 회원 등급을 제외하고 상품 ID 만 써서 먼저 조회한 사용자의 등급 가격이 다른 등급 사용자에게 나간다(먼저 고른다), 캐시 키를 문자열로 이어 쓰면서 구분자를 생략해 `"12" + "3"` 과 `"1" + "23"` 이 같은 키가 된다.
- 버그 신고: "일반 회원에게 VIP 할인가가 보인다는 문의가 들어왔다. 늘 그런 것은 아니다."
- 형식: 180~260줄, 파일 3~4개.
- 난도: 요청 순서에 따라 증상이 나거나 나지 않아 재현 순서를 찾아야 한다.
- 검증: 숨은 테스트는 등급이 다른 사용자가 같은 상품을 조회하는 순서를 바꿔 둔다. 키에 등급을 넣거나 data class 키로 바꾼 수정이 모두 통과해야 한다.
- 출처: load README 의 '캐시' 절.
- 피할 것: 동시성 경쟁 상태까지 섞는 것. L-load-30~L-load-60 의 캐시 실험과 같은 주제.
