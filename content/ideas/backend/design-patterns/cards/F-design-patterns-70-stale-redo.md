# F-design-patterns-70 다시 실행하면 끼어드는 옛 편집

- 맥락: 상품 설명 편집기의 되돌리기와 다시 실행. 편집 하나는 커맨드 객체이고 되돌리기 스택과 다시 실행 스택을 따로 둔다. 커맨드는 실행할 때의 위치와 내용을 기억한다.
- 버그 후보: 새 편집을 실행할 때 다시 실행 스택을 비우지 않아, 되돌린 뒤 새로 편집하고 다시 실행하면 옛 편집이 바뀐 문서에 적용된다(먼저 고른다). 되돌리기가 커맨드가 기억한 위치 대신 현재 커서 위치를 써서 다른 글자를 지우는 경우.
- 버그 신고: "되돌리기를 누른 뒤 새로 입력하고 다시 실행을 누르면 내가 쓰지 않은 문장이 끼어든다."
- 형식: 200~280줄, 파일 3~4개.
- 난도: 되돌리기와 다시 실행 기록이 언제 무효가 되는지 알아야 원인에 닿는다.
- 검증: 숨은 테스트는 되돌리기, 새 편집, 다시 실행이 섞인 순서를 여러 개 둔다. 새 편집에서 다시 실행 기록을 비우는 수정이 통과해야 한다.
- 출처: GoF(Command, Memento).
- 피할 것: B-design-patterns-80과 같은 명령 문법, 편집기 전체를 다시 구현하게 하는 것.
