# R-coroutines-10 코루틴과 구조적 동시성

- 분야: 기술(프로그래밍 언어)
- 목표: 중단 함수가 스레드를 놓고 다시 이어지는 원리와 구조적 동시성의 취소·예외 규칙을 이해하고 실행 시간표에 적용한다.
- 다룰 내용: 스레드를 막는 대기와 중단의 차이, Continuation 과 상태 기계, 부모-자식 Job 관계와 완료 조건, 협력적 취소(중단 지점에서 확인, 계산 반복문의 직접 확인), 취소 예외를 삼키는 코드의 결과, 예외가 부모와 형제로 퍼지는 규칙과 감독자, 루트 코루틴에서만 쓰이는 예외 처리기.
- 난도: LEET 언어이해 수준.
- 형식: 2,900~3,300자, 7~8문단, 6문항. `<보기>` 하나는 부모 하나와 자식 셋의 시간표(지연, 실패, 취소)를 주고 각 코루틴이 끝나는 시각과 결과를 묻는다. 다른 하나는 `catch` 로 예외를 처리하는 세 가지 코드 모양을 글로 주고 취소가 전파되는지 묻는다.
- 함정과 엣지 케이스: 취소하면 곧바로 멈춘다고 본 선지, 자식에 설치한 예외 처리기가 불린다고 본 선지, 감독자 아래에서도 형제가 취소된다고 본 선지, async 의 예외가 await 없이 사라진다고만 본 선지(부모가 있으면 부모를 취소한다).
- 검증: 시간표 결과는 kotlinx.coroutines 로 실행해 확인한다.
- 출처: 이 도메인 README 의 '출처' 절.
- 피할 것: 라이브러리 함수 이름을 외워야 풀리는 문항. 원리를 묻는다.
