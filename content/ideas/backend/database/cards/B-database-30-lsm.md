# B-database-30 LSM 저장소 만들기

- 목표: 메모리 테이블, 정렬 파일, 압축, 블룸 필터로 이뤄진 LSM 키-값 저장소를 만들고 증폭 지표를 잰다.
- 1단계 `01-memtable`: 쓰기와 삭제(툼스톤), 크기 한도에서 정렬 파일로 내리기, 최신 값부터 찾는 읽기.
- 2단계 `02-compaction`: 레벨 압축 규칙(레벨 크기 비율, 겹치는 파일 고르기)을 명세가 정하고 쓰기 증폭과 공간 증폭을 보고한다. 마지막 레벨에서 툼스톤 지우기.
- 3단계 `03-bloom-and-range`: 파일마다 블룸 필터(해시 함수와 비트 수는 명세가 정함)로 없는 키 읽기를 줄이고 거짓 양성 수를 센다. 여러 레벨을 합치는 범위 조회.
- 난도: 단계마다 2~3시간.
- 함정: 툼스톤을 너무 일찍 지워 옛 값이 되살아나는 경우, 같은 키의 여러 버전, 범위 조회의 경계와 삭제된 키.
- 검증: build 스킬의 교차 검증. 생성기 입력으로 단순한 맵 구현과 결과를 대조한다.
- 출처: O'Neil 외 1996, Kleppmann DDIA 3장.
- 피할 것: 실제 파일 입출력 성능을 채점하는 것. 증폭은 명세가 정한 단위로 센다.
