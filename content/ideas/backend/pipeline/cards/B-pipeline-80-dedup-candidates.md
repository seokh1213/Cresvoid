# B-pipeline-80 중복 후보 생성과 대표 선택기 만들기

- 목표: 정확히 같은 항목을 먼저 묶고 비싼 쌍 비교를 줄이면서도 명세가 정한 중복 결과를 보존한다. 중복 판정의 직접 연결과 연결 요소의 대표를 구분한다.
- 입출력 모양: 항목 id·범주·시각·정렬된 정수 토큰 집합을 등록하고 정확 일치 그룹, 후보쌍, 중복 그룹과 비교 횟수를 출력한다. 입력은 이미 정규화한 토큰이며 자연어 전처리는 하지 않는다.
- 1단계 `01-exact`: 같은 범주·토큰 집합을 묶고 시각이 가장 늦은 항목을 대표로 고른다. 같은 시각은 id 순으로 정한다. 원래 id 목록은 보존한다.
- 2단계 `02-candidates`: 서로 다른 정확 일치 그룹 사이의 유사도를 토큰 집합의 Jaccard 값으로 정한다. 임계값은 정수 분수로 받고 정수 비교로 판정한다. 범주가 다르거나 집합 크기로 계산한 최대 유사도가 임계값에 못 미치면 비교에서 제외한다. 그 밖의 쌍을 빠뜨리지 않는 후보 생성을 구현하고 실제 판정 횟수를 센다.
- 3단계 `03-components`: 중복 판정을 간선으로 삼아 연결 요소를 만들고 최신 항목을 대표로 출력한다. A-B, B-C가 연결되어도 A-C가 직접 중복쌍이라는 뜻은 아니다. 정확 일치 그룹을 원래 id로 다시 펼치며 대표 삭제 뒤의 재계산도 다룬다.
- 난도: 단계마다 1~3시간. 대규모 입력은 정확 일치가 많은 경우와 크기가 다른 토큰 집합을 섞는다. 올바른 후보 제외로 줄일 수 없는 비교까지 숨은 시간 제한으로 강제하지 않는다.
- 함정: 빈 집합의 유사도, 임계값과 같은 값, 자기 쌍·역순 쌍 중복, 대표의 바뀐 시각, 연결의 전이성과 직접 유사도의 혼동. 빈 집합 규칙과 정수 범위는 스펙에 명시한다.
- 검증: 작은 입력의 모든 쌍을 독립적으로 비교한 결과와 직접 중복쌍·연결 요소·대표를 대조한다. 비교 횟수의 정의와 정확 일치 처리를 별도로 검사한다. 결과가 같은지만 보고 잘못된 비용 집계를 통과시키지 않는다.
- 출처: [Python Record Linkage Toolkit Indexing](https://recordlinkage.readthedocs.io/en/latest/ref-index.html)의 full indexing과 blocking. 유사도·범주 제한·대표·동점과 비용 계산은 이 과제의 규칙이다.
- 피할 것: GraphX·Spark·Python 라이브러리 설치, 근사 분할을 결과 보존 최적화로 설명하는 것. 근사의 손실은 L-pipeline-90에서 따로 다룬다.
