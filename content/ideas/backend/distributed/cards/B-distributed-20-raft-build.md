# B-distributed-20 Raft 시뮬레이터 만들기

- 목표: 노드 여러 개와 네트워크를 흉내 내는 결정적 시뮬레이터 위에서 Raft 를 구현한다.
- 입출력 모양: 노드 만들기(선거 타임아웃 값은 입력으로 줌), `TICK`, 메시지 전달·지연·유실, 네트워크 분할과 복구, 클라이언트 요청, 상태 조회 명령이다. 같은 시각에 생긴 메시지의 전달 순서는 명세가 정한다.
- 1단계 `01-election`: 팔로워·후보·리더 상태, 임기, 투표 요청과 응답, 표 갈림과 재선거, 높은 임기를 보면 물러나기.
- 2단계 `02-replication`: 로그 항목 덧붙이기, 일관성 검사와 어긋난 로그 덮어쓰기, 팔로워별 다음 인덱스 낮추기.
- 3단계 `03-commit`: 커밋 인덱스 계산(현재 임기 항목만 과반수로), 상태 기계에 적용, 분할된 소수 쪽 리더의 요청이 커밋되지 않는 것, 최신 로그 조건의 투표.
- 난도: 단계마다 3시간 안팎.
- 함정: 같은 임기에 두 번 투표, 오래된 응답 처리, 이전 임기 항목의 커밋, 메시지가 늦게 도착한 뒤의 상태.
- 검증: build 스킬의 교차 검증. 안전성 성질(한 임기에 리더 하나, 커밋된 항목은 사라지지 않음)을 생성기 시나리오마다 확인한다.
- 출처: Ongaro, Ousterhout USENIX ATC 2014.
- 피할 것: 공개된 Raft 구현 코드를 참조 풀이에 옮기는 것. 논문의 규칙만 근거로 쓴다.
