# B-distributed-40 일관 해싱 만들기

- 목표: 키를 노드에 나누는 해시 링을 만들고 노드가 들고 날 때 옮기는 키를 최소로 줄이는 원리를 구현으로 익힌다.
- 입출력 모양: 표준 입력의 명령으로 노드를 추가하고 제거하며 키의 소유 노드와 옮겨진 키를 출력한다. 해시 함수는 명세가 고정한다(예: 64비트 FNV-1a).
- 1단계 `01-ring`: 노드와 키를 같은 해시 공간에 놓고 시계 방향으로 처음 만나는 노드에 키를 배정한다. 노드를 추가하고 제거할 때 옮겨지는 키 목록을 출력한다.
- 2단계 `02-rebalance`: 노드마다 가상 노드를 여러 개 두고 용량에 비례해 가상 노드 수를 정한다. 노드별 키 수의 최댓값과 평균의 비율을 출력한다.
- 3단계 `03-replication`: 키마다 링을 시계 방향으로 따라가며 서로 다른 물리 노드 N개를 고른다(선호 목록). 노드를 제거할 때 복제본이 N개보다 적어진 키와 새로 복제할 노드를 출력한다.
- 난도: 단계마다 1~2시간.
- 함정: 해시 공간 끝에서 처음으로 감기, 같은 해시값을 가진 토큰의 동점 규칙, 가상 노드 때문에 같은 물리 노드가 복제본으로 두 번 선택되는 경우, 키 범위 경계의 포함 여부.
- 검증: build 스킬의 교차 검증. 생성기가 노드 추가·삭제와 키 추가를 섞고 모든 키를 매번 다시 배정하는 단순 구현과 옮겨진 키 목록을 비교한다.
- 출처: Karger 외, "Consistent Hashing and Random Trees", STOC 1997. DeCandia 외, "Dynamo: Amazon's Highly Available Key-value Store", SOSP 2007(가상 노드, 서로 다른 물리 노드만 담는 선호 목록). System Design Interview 1권 5장의 주제.
- 피할 것: 실제 네트워크와 데이터 전송, 점프 해시와 랑데부 해시까지 한 트랙에서 함께 다루는 것.
