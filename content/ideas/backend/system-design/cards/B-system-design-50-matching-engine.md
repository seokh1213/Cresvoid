# B-system-design-50 주문 매칭 엔진 만들기

- 목표: 가격-시간 우선 규칙으로 주문을 체결하는 엔진을 만들고 이벤트 기록으로 상태를 복원한다.
- 1단계 `01-order-book`: 지정가 매수·매도, 가격 우선과 시간 우선, 부분 체결, 취소, 호가 단계별 잔량 출력.
- 2단계 `02-order-types`: 시장가, 즉시 체결하고 남은 것은 취소(IOC), 전량 체결이 아니면 취소(FOK), 정정.
- 3단계 `03-replay`: 순서 번호를 매긴 입력 기록에서 같은 상태와 체결을 다시 만들기, 스냅숏과 그 뒤 기록으로 복원하기.
- 난도: 단계마다 2~3시간. 대규모 테스트는 주문 100만 건이다. 체결마다 호가 전체를 훑으면 제한 시간을 넘게 만든다.
- 함정: 같은 가격의 도착 순서, 정정이 시간 우선을 잃는 경우, 수량 0 주문, 자기 주문끼리의 체결 규칙.
- 검증: build 스킬의 교차 검증. 생성기 입력에서 체결 수량 합이 양쪽 감소량과 같은지 확인한다.
- 출처: System Design Interview 2권 13장의 주제.
