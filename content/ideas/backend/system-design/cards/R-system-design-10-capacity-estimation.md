# R-system-design-10 규모 추정

- 분야: 기술(시스템 설계)
- 목표: 사용자 수에서 초당 요청 수, 저장 공간, 대역폭을 어림하는 추론 과정을 따라가고 숫자 자료에 적용한다.
- 다룰 내용: 일 활성 사용자에서 평균 초당 요청 수와 최대 초당 요청 수로 가는 계산, 읽기·쓰기 비율, 저장 공간 증가와 복제 배수, 캐시 적중률이 원천 부하를 줄이는 계산, 가용성 9의 개수와 1년 중 허용 중단 시간, 저장 장치와 네트워크 지연의 자릿수 차이, 어림셈에서 가정을 밝히는 이유.
- 난도: 수능 기술 지문 고난도. 계산 `<보기>` 로 변별한다.
- 형식: 2,600~3,000자, 7문단, 6문항. `<보기>` 하나는 서비스 조건을 주고 최대 초당 쓰기 수와 5년 저장 공간을 계산하게 한다. 다른 하나는 캐시 적중률과 원천 한도를 주고 견딜 수 있는 최대 요청 수를 묻는다.
- 함정과 엣지 케이스: 평균과 최대를 섞은 계산, 복제 배수를 빠뜨린 저장 공간, 비트와 바이트 혼동, 적중률이 오를 때 원천 부하가 줄어드는 비율.
- 검증: `<보기>` 계산은 Kotlin 스크립트로 확인한다.
- 출처: System Design Interview 1권 2장의 주제. 지연 자릿수는 지문에서 값을 직접 준다.
- 피할 것: 해마다 바뀌는 하드웨어 수치를 정답 근거로 삼는 것.
