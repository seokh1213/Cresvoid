# R-ai-agent-10 에이전트 루프와 도구 호출

- 분야: 기술(인공지능 시스템)
- 목표: 에이전트가 도구를 호출하고 결과를 받아 다음 행동을 정하는 순환을 규약 수준에서 따라가고 설계 선택의 이유를 판단한다.
- 다룰 내용: 증강 LLM, 워크플로와 에이전트의 구별, 도구 정의와 입력 스키마, 도구 사용 요청과 결과의 짝 맞추기(식별자, 순서 규칙), 오류 결과를 돌려주면 모델이 고쳐 다시 시도하는 원리, 병렬 도구 호출, 컨텍스트가 길어질수록 회상이 떨어지는 현상과 컴팩션, 도구 결과에 섞인 지시가 모델을 조종하는 간접 프롬프트 주입과 그 방어(신뢰 경계, 되돌릴 수 없는 행동의 사람 확인).
- 난도: 수능 기술 지문 최고난도.
- 형식: 2,800~3,200자, 7~8문단, 6문항. `<보기>` 하나는 메시지 기록(사용자 요청, 도구 사용, 도구 결과, 응답)을 주고 규약을 어긴 곳과 그 결과를 묻는다. 다른 하나는 업무 사례 세 개를 주고 워크플로 패턴과 에이전트 가운데 알맞은 설계를 묻는다.
- 함정과 엣지 케이스: 도구 결과 앞에 텍스트를 둔 메시지, 식별자가 맞지 않는 결과, 오류를 빈 결과로 숨긴 경우, 도구 결과 속 지시를 사용자 지시로 다룬 설계, 단계 수가 정해진 일에 에이전트를 쓴 선지.
- 검증: 규약 서술은 Claude 문서(Define tools, Handle tool calls)와 대조한다. 판마다 바뀌는 세부(모델별 제약)는 지문에 넣지 않는다.
- 출처: Building effective agents, Effective context engineering for AI agents, Claude 도구 사용 문서.
- 피할 것: 특정 제품의 기능 이름을 외워야 풀리는 문항. 원리를 묻는다.
