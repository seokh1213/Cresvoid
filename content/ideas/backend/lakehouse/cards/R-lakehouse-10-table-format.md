# R-lakehouse-10 테이블 포맷과 원자적 커밋

- 분야: 기술(데이터 저장)
- 목표: 파일 여러 개를 한 테이블로 다루는 메타데이터 계층과 동시 쓰기 규칙을 이해하고 커밋 시간표에 적용한다.
- 다룰 내용: 디렉터리 테이블의 한계, 메타데이터 파일에서 데이터 파일까지의 계층, 메타데이터 교체로 얻는 원자성과 직렬화 격리, 낙관적 커밋과 재시도, 숨은 파티셔닝과 파티션 진화, 필드 ID 기반 스키마 진화, 위치 삭제와 동등 삭제.
- 난도: 수능 기술 지문 최고난도.
- 형식: 2,800~3,200자, 7~8문단, 6문항. `<보기>` 하나는 두 작업이 같은 기준 스냅숏에서 시작해 커밋하는 시간표를 주고 각 커밋의 결과와 재시도를 묻는다. 다른 하나는 열 이름을 바꾼 뒤 옛 파일을 읽는 상황을 준다.
- 함정과 엣지 케이스: 읽는 쪽이 커밋 도중의 상태를 본다고 착각한 선지, 재시도가 처음부터 다시 쓴다고 비튼 선지, 이름으로 열을 고른다고 착각한 선지.
- 검증: Iceberg Table Spec 원문과 대조한다.
- 출처: Iceberg Table Spec.
- 피할 것: 형식 세부(매니페스트 필드 이름)를 외워야 풀리는 문항.
