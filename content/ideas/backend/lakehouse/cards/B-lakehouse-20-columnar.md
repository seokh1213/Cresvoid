# B-lakehouse-20 열 지향 파일 만들기

- 목표: 열 지향 파일 포맷의 행 그룹, 열 조각, 페이지, 부호화, 통계를 구현하고 술어 푸시다운이 읽는 양을 얼마나 줄이는지 측정한다.
- 입출력 모양: 스키마 정의, 행 적재, 파일 쓰기(행 그룹 크기와 페이지 크기 인자), 질의(열 선택과 술어), 읽은 행 그룹 수·페이지 수·바이트 수 보고 명령이다. 파일 형식은 명세가 정한 단순한 바이트 배치다.
- 1단계 `01-encode`: 열마다 평문, 사전, 런 길이 부호화를 고르는 규칙과 부호화된 크기 계산. 같은 데이터를 다시 읽어 같은 행을 돌려준다.
- 2단계 `02-pruning`: 행 그룹과 페이지의 최솟값·최댓값 통계, 같음·범위·IN·IS NULL 술어의 건너뛰기, 정렬 여부에 따른 읽은 양 차이. 대규모 테스트는 정렬하지 않으면 건너뛰기가 거의 없는 데이터를 준다.
- 3단계 `03-nested`: 반복·정의 수준으로 중첩 목록과 선택 필드를 평평한 열에 담고 되살린다.
- 난도: 1·2단계는 2시간 안팎, 3단계는 3시간.
- 함정: NULL 이 섞인 열의 통계, 모든 값이 NULL 인 페이지, 사전이 커지면 평문으로 바꾸는 경계, 빈 목록과 NULL 목록의 구분.
- 검증: build 스킬의 교차 검증. 3단계는 Dremel 논문의 예시로 대조한다.
- 출처: Parquet 문서(Configurations, Page Index), Melnik 외 VLDB 2010.
- 피할 것: 실제 Parquet 바이트 형식(Thrift 메타데이터)을 요구하는 것.
