# R-messaging-10 복제와 전달 보장

- 분야: 기술(분산 메시징)
- 목표: 메시지가 사라지거나 두 번 오는 조건을 복제, 확인 응답, 커밋 시점으로 따져 장애 시간표에 적용한다.
- 다룰 내용: 파티션과 순서, 리더와 팔로워, 동기 복제본 집합, 확인 응답 수준(acks), 최소 동기 복제본 수, 동기화되지 않은 복제본의 리더 선출, 멱등 프로듀서의 시퀀스 번호, 컨슈머 그룹과 오프셋 커밋 시점에 따른 최소 한 번과 최대 한 번.
- 난도: 수능 기술 지문 최고난도.
- 형식: 2,800~3,200자, 7~8문단, 6문항. `<보기>` 하나는 브로커 장애와 리더 교체 시간표를 주고 설정별로 남는 메시지를 묻는다. 다른 하나는 컨슈머가 처리 도중 멈추는 시간표를 주고 다시 처리되는 메시지를 묻는다.
- 함정과 엣지 케이스: acks=all 이면 언제나 세 복제본에 있다고 본 선지(최소 동기 복제본 수 1), 자동 커밋을 처리 완료로 본 선지, 파티션을 늘려도 키 순서가 유지된다고 본 선지.
- 검증: 기본값과 규칙은 Kafka 문서로 확인한다. 시간표는 Kotlin 스크립트로 시뮬레이션해 확인한다.
- 출처: 이 도메인 README 의 '출처' 절.
- 피할 것: 버전별 기본값을 정답 근거로 삼는 것. 필요한 설정은 `<보기>` 에서 준다.
