# L-load-40 캐시 관통과 동시 만료

- 모드: implement
- 난도: 보통.
- 목표: 없는 키와 동시 만료가 원천으로 새는 길을 막는다.
- 서비스: L-load-30 과 같은 상품 조회 서비스. 원천의 초당 처리 한도는 300 이다.
- 비울 핵심: TTL 계산(지터), 음성 캐시, 원천 동시 호출 상한.
- 시나리오 A: 요청의 30% 가 존재하지 않는 id 다. 시나리오 B: 키 1만 개를 0초에 같은 TTL 로 채우고 만료 시점을 지나며 계속 조회한다.
- 불변식: A 는 없는 id 의 원천 조회 수 ≤ 서로 다른 id 수 × (실행 시간 / 음성 TTL + 1). B 는 초당 원천 호출 최댓값 ≤ 300, 5xx 0건.
- 문항이 노릴 것: 음성 캐시 TTL 이 길 때 새 데이터가 안 보이는 시간, 지터 폭과 분산, 블룸 필터의 거짓 양성, 캐시 재시작 뒤의 예열.
