# 프로젝트 문서

Cresvoid의 공개 문서다.

- [에이전트 작업 규칙](agents.md): 작업 시작과 종료, 콘텐츠 제작, 검증 기준.
- [설계 결정](decisions.md): 엔진·콘텐츠 형식·의존성을 정한 이유.
- [코루틴 완성 계획](coroutines-roadmap.md): 현재 콘텐츠, 진행 범위, 후속 아이디어.

작업 중에는 `docs/handoff.md`에 맡은 대상과 진행 상태를 쓰고 `docs/log/YYYY-MM-DD-주제.md`에 판단과 검증 결과를 남겨라. 두 경로와 `docs/local/`의 개인 작업 자료는 `.gitignore`로 공개에서 제외한다. 처음 복제한 저장소에 파일이 없으면 작업을 시작할 때 만들어라. 콘텐츠 제작 절차는 `content/skills/`를 따른다.
